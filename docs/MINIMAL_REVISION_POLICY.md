# Minimal Revision Policy

The automatic revision step is intentionally conservative.

Rules:
- Execute only the corrections explicitly requested by the verifier.
- Preserve every supported sentence unless a correction requires changing it.
- Never add a new argument, example, statistic, quotation, scholar name, book, URL, or page merely because it exists in retrieved evidence.
- Revised answers must return to Citation Verification before continuing.
- Sources after revision may only be retained or removed from the previous `sources_used`, except for an explicit correction of an existing source using evidence metadata.
