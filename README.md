# بيّنة | Bayyinah

مساعد معرفي دعوي يهدف إلى تمكين العاملين في التعريف بالإسلام من الوصول إلى إجابات موثقة وقابلة للتتبع، مع طبقات تحقق من الأدلة والاستشهادات والترجمة، ومراجعة بشرية عند الحاجة.

## Live Demo
- Telegram: https://t.me/Dawah_Eri_bot

## ماذا يفعل النظام؟
1. يستقبل سؤال الداعية عبر Telegram.
2. يبحث في قاعدة المعرفة الداخلية باستخدام RAG.
3. يقيّم كفاية الأدلة قبل بناء الإجابة.
4. عند الحاجة يعيد صياغة استعلام الاسترجاع ويجرب مرة ثانية.
5. إذا بقيت الأدلة غير كافية ينتقل إلى مصادر خارجية معتمدة.
6. يبني إجابة عربية مستندة إلى الأدلة.
7. يتحقق من الادعاءات والاستشهادات، ويصحح الإجابة تلقائيًا عند الإمكان.
8. يترجم الإجابة إلى التغرينية، ثم يتحقق من الترجمة ويحاول تصحيحها.
9. إذا لم تجتز أي مرحلة حرجة التحقق، يُحال الطلب إلى مراجع بشري.
